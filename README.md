# VECINDAD

**Entender. Preguntar. Participar.**

VECINDAD es un sistema educativo ciudadano para aprender a investigar temas de San Patricio del Chañar.

## Arquitectura

- `index.html`: superficie visual.
- `styles.css`: experiencia responsive.
- `app.js`: motor de navegación, búsqueda y casos.
- `data/master.js`: cerebro inicial del sistema.
- `data/sources.js`: registro de fuentes.
- GitHub Pages: publicación estática, sin backend.

## Mapa Maestro 1.0

El sistema relaciona:

**pregunta → contexto → actores → competencia → norma → evidencia → escenarios → acción → fuentes**

### Regla de evidencia

Una afirmación no se convierte automáticamente en hecho porque aparezca en una conversación, red social o publicación. Debe existir una fuente adecuada o quedar marcada como investigación abierta.

### Regla jurídica

La Carta Orgánica, las ordenanzas, los actos municipales y las normas provinciales/nacionales se incorporan con verificación documental. No se inventan artículos ni competencias.

### Regla pedagógica

La interfaz debe poder ser entendida por una persona sin conocimientos jurídicos. La profundidad vive en la estructura de datos, las relaciones y las fuentes; no en párrafos interminables.
